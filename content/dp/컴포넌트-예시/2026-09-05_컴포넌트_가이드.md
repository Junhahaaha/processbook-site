# 인터랙션 컴포넌트 사용법

노트 어디서든 아래 형태로 코드블록을 쓰면 사이트가 알아서 컴포넌트로 바꿔서 보여줍니다. 코드블록 언어 이름(```뒤에 붙는 단어)만 정확히 맞추면 되고, 그 안의 내용은 자유롭게 채우면 됩니다.

## 일반 이미지 (별도 문법 없음)

그냥 옵시디언에서 드래그해서 넣는 평범한 이미지 임베드입니다. 사이트에서는 클릭하면 확대(zoom)되는 기능이 자동으로 붙습니다.

![](/content/dp/컴포넌트-예시/예시_before.jpg)

## Before / After 오버레이

아래 이미지 → 위 이미지 순서로 파일명 두 줄. 사이트에서는 슬라이더로 위 이미지의 불투명도를 조절합니다.

```before-after
/content/dp/컴포넌트-예시/예시_before.jpg
/content/dp/컴포넌트-예시/예시_after.jpg
```

## 이미지 갤러리 (스와이프)

여러 장을 줄마다 나열하면 마우스 드래그로 넘겨볼 수 있는 캐러셀이 됩니다.

```gallery
/content/dp/컴포넌트-예시/예시_갤러리1.jpg
/content/dp/컴포넌트-예시/예시_갤러리2.jpg
/content/dp/컴포넌트-예시/예시_갤러리3.jpg
```

## 커서 스위치

기본 이미지 → 호버 이미지 순서로 두 줄. 마우스를 올리면 이미지가 바뀝니다.

```cursor-switch
/content/dp/컴포넌트-예시/예시_기본.jpg
/content/dp/컴포넌트-예시/예시_호버.jpg
```

## 스티커 (애니메이션 이모티콘)

문장 밑에 넣으면 작은 크기로 2프레임을 반복 재생하는 애니메이션 스티커가 됩니다. 프레임1 → 프레임2 순서로 두 줄.

오늘 작업하다가 이런 느낌이었음:

```sticker
/content/dp/컴포넌트-예시/예시_스티커_1.png
/content/dp/컴포넌트-예시/예시_스티커_2.png
```

## 컬러 칩

헥스 코드를 줄마다 나열하면 색상 스와치 카드로 표시됩니다. 클릭하면 복사됩니다.

```color-chip
#2f5d50
#c0563f
#3f7cc0
#c99a2e
```

## 링크 카드 (명함형)

URL을 줄마다 나열하면 빌드할 때 그 사이트의 제목/설명/썸네일을 가져와 카드로 보여줍니다.

```link-card
https://obsidian.md
https://nextjs.org
```

## 피드백 하이라이트

교수님/동료 피드백을 인용할 때 씁니다. 카드마다 다른 색이 자동으로 배정되고, 화면 우측 하단 북마크 독에도 그 색으로 표시됩니다.

```feedback
전체적인 구도는 좋은데, 타이포그래피 크기를 조금 더 키워보면 어떨까요?
```

중간에 다른 내용을 쓰다가 또 피드백이 나오면:

```feedback
다음 주까지 색상 팔레트 후보를 3개 더 만들어서 비교해보기로 함.
```

## 토글 기록 (접었다 펼치기)

길어지는 기록이나 곁다리 메모를 접어둘 때 씁니다. **첫 줄이 제목**(항상 보임)이고, 그 아래가 펼쳤을 때 나오는 본문입니다. 본문에는 문단·목록·굵게·링크·이미지 같은 일반 마크다운을 쓸 수 있어요 (다른 코드블록 컴포넌트는 중첩 불가).

```toggle
회의 메모 (2026-09-05)
- 레이아웃 방향은 세로 스크롤로 확정
- 다음 회의까지 색상 후보 3개
- **결정 필요**: 타이포 스케일
```

제목만 쓰고 본문을 비워도 됩니다:

```toggle
아직 정리 안 된 아이디어들 (나중에)
```
